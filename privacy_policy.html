Политика конфиденциальности - Manga.garden Tool

Дата вступления в силу: 22 февраля 2026 года

Версия: 1.0

1. Общая информация

Расширение "Manga.garden Tool" (далее - "Расширение") разработано для помощи пользователям в добавлении манги в лист отслеживания на сайте manga.garden. Мы серьезно относимся к конфиденциальности пользователей и стремимся защищать их личные данные.

2. Собираемые данные

2.1. Данные, которые НЕ собираются

Расширение НЕ собирает:

  • Личную информацию пользователей
  • Историю браузера
  • Файлы cookie
  • Данные для входа в аккаунты
  • Финансовую информацию
  • Местоположение пользователя

2.2. Данные, которые обрабатываются локально

Расширение использует следующие данные только локально в браузере пользователя:

  • Настройки расширения - хранятся локально с помощью chrome.storage.local
  • Выбранные элементы DOM - временно хранятся для работы инструмента выбора
  • URL текущей страницы - используется только для отправки на manga.garden по запросу пользователя

3. Использование разрешений

3.1. Разрешение "contextMenus"

Обоснование: Для добавления пункта "manga.garden" в контекстное меню браузера, чтобы пользователи могли быстро активировать инструмент выбора элементов на страницах с мангой.

Использование: Разрешение используется только для создания контекстного меню и обработки кликов по нему. Не используется для сбора данных о кликах пользователя.

3.2. Разрешение "storage"

Обоснование: Для сохранения настроек расширения локально в браузере пользователя, чтобы сохранять предпочтения между сессиями.

Использование: Хранит только настройки интерфейса (например, положение окна инструмента). Все данные хранятся локально и не передаются на серверы.

3.3. Разрешения хостов "http://*/*" и "https://*/*"

Обоснование: Для работы на всех веб-страницах, где пользователь может находить мангу для добавления в список отслеживания.

Использование: Контент-скрипты расширения встраиваются на страницы только для:

  • Отображения инструмента выбора элементов
  • Выделения выбранных элементов на странице
  • Отправки выбранных данных на manga.garden только по явному запросу пользователя (кнопка "✔️")

4. Передача данных

Расширение передает данные только в одном случае:

  • Когда пользователь явно нажимает кнопку "✔️" в интерфейсе расширения, следующие данные отправляются на manga.garden:
    • URL текущей страницы
    • Выбранный элемент DOM (в виде CSS-селектора)
    • Выделенный блок DOM (в виде CSS-селектора)

Все данные передаются только по запросу пользователя и только на сайт manga.garden для добавления в список отслеживания.

5. Безопасность данных

Все данные обрабатываются локально в браузере пользователя. Расширение не имеет серверной части и не хранит данные пользователей на внешних серверах.

6. Изменения в политике конфиденциальности

Мы можем обновлять эту политику конфиденциальности по мере развития расширения. Все изменения будут отражены на этой странице с указанием даты обновления.

7. Контакты

Если у вас есть вопросы относительно этой политики конфиденциальности или работы расширения, пожалуйста, свяжитесь с нами через магазин расширений Chrome.
