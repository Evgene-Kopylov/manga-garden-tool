# Manga.garden Tool

Расширение Chrome для добавления манги в лист отслеживания на manga.garden.

## Установка

### Из Chrome Web Store

[Установить из интернет-магазина Chrome](https://chrome.google.com/webstore/detail/mangagarden-tool/nnfklgpgpedojmanekcpgmpgjkdfhkbd)

### Как распакованное расширение

1. Скачайте или клонируйте репозиторий
2. Откройте Chrome и перейдите в `chrome://extensions/`
3. Включите "Режим разработчика" (Developer mode)
4. Нажмите "Загрузить распакованное расширение" (Load unpacked)
5. Выберите папку с расширением

## Использование

1. На любой странице с мангой кликните правой кнопкой мыши
2. Выберите "manga.garden" в контекстном меню
3. Появится окно инструмента с выделенным элементом
4. Используйте кнопки:
   - `Q` / `W` - для перемещения по DOM-дереву вверх/вниз
   - `✔️` - отправить выбранный элемент на manga.garden
   - `✖️` - закрыть окно инструмента

## Особенности

- Поддержка Manifest V3 (совместимо с современными версиями Chrome)
- Перетаскиваемое окно (захватите заголовок или свободную область)
- Выделение элементов на странице
- Сохранение позиции окна после перетаскивания
- Локализация (русский/английский)

## Настройка

Переменная `MANGA_TRACKER_URL` в `tool_content.js` содержит URL домашней страницы для отправки данных.

## Версия

Текущая версия: 1.0.0 (Manifest V3)
